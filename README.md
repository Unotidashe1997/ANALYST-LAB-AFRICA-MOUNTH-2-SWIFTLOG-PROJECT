## Headline results
- 33.2% of orders Delivered, 32.5% Cancelled, 34.3% Pending; confirmed order value 14.44M (gross 21.67M).
- 63.7% of shipments delayed 3+ days; no warehouse, region or order type is significantly different.
- 1,626 shipments are recorded on Cancelled orders: status and shipment records disagree.
- 10 hypothesis tests: none significant; best delay-model AUC 0.52 (chance = 0.50).
- 15 strategic recommendations (Part 7).

## Method notes and assumptions
- Revenue is not in the data: LineValue = Quantity × UnitPrice. Three views: gross, confirmed (non-cancelled, default), delivered.
- DelayDays ≥ 3 = Delayed (matches the supplied delivery status).
- Repeated Inventory keys are treated as stock lots and summed (sensitivity: rank correlation 0.82).
- September 2026 is partial (data ends 8 Sep) and is excluded from trends.
- Features use only prior information (no leakage); delay days, returns and status are never predictors.

## Known limitations
- **Suppliers:** no table links suppliers to products, stock or shipments, so supplier analysis is impossible. A warehouse Reliability Score is used as a labelled substitute.
- No warehouse capacity, carrier, or ship/delivery dates; workload per employee is a proxy.
- `ydata-profiling`, Jupyter and plotly could not be installed (no package-index access). The profiling report is generated by custom code in the notebook, and the notebook was executed with a custom runner (`Notebook/src/notebook_runner.py`) that writes a standard `.ipynb` with real outputs. Charts use Matplotlib/Seaborn.
